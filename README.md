# Трекер привычек (Habit Tracker)

Современное веб-приложение для формирования устойчивых привычек, отслеживания ежедневных ритуалов, серий побед и анализа личного прогресса.

---

## 🚀 Текущий функционал приложения

- **Ежедневный ритм («Сегодня»)**:
  - Интерактивная 7-дневная календарная лента с быстрым переключением между датами и мгновенным возвратом к «Сегодня».
  - Динамическая шкала дневного прогресса с расчётом процента выполненных задач и вдохновляющими подсказками.
  - Карточки привычек с цветовой кодировкой, иконками, тегами категорий (Здоровье, Спорт, Разум, Продуктивность, Стиль жизни) и фильтром по времени суток (Утро, День, Вечер).
  - Счётчик непрерывных серий выполнения с визуальным индикатором (🔥).
  - Микро-интеракции: тактильный отклик, плавная анимация переключения статуса и праздничный конфетти-эффект при завершении цели.
  - Быстрый поиск по названию и фильтрация по категориям и времени дня.

- **Сетка недели («Сетка»)**:
  - Матричный обзор всех привычек в формате интерактивной таблицы с разбивкой по дням недели.
  - Возможность просматривать и отмечать выполнение за любой день недели одним кликом без переключения экранов.
  - Итоговая статистика выполнения для каждой привычки и сводка по дням.

- **Аналитика и статистика**:
  - Карточки ключевых метрик: активные привычки, лучшая серия (рекорд), суммарное количество выполнений, процент соблюдения дисциплины за 30 дней.
  - 9-недельная тепловая карта активности (Heatmap) в стиле вкладов GitHub с градиентной шкалой интенсивности.
  - Рейтинг привычек по стабильности выполнения.
  - Практические советы по психологии привычек (правило двух минут, связывание привычек, принцип «не пропускать дважды»).

- **Персонализация и дизайн**:
  - Модальное окно создания и редактирования привычек с выбором названия, описания, категории, иконки, цвета, времени суток и регулярности (ежедневно, по будням, по выходным).
  - Поддержка светлой и тёмной темы оформления с автосохранением предпочтений.
  - Надёжное локальное хранилище (`localStorage`) с функцией восстановления демонстрационных данных.

## 📊 План расширения: Визуализация прогресса (дни, недели, месяцы)

Ниже представлена архитектура и концепция добавления расширенной аналитики:

### 1. Дневной срез (Daily Trend)
- **График скользящей средней (7-дневный тренд)**:
  - Линейный график или диаграмма с областями (Area Chart), показывающая процент закрытых привычек по каждому дню за последние 14–30 дней.
  - Скользящее среднее сглаживает случайные единичные пропуски и наглядно демонстрирует общий тренд (рост или спад продуктивности).
- **Почасовое распределение**:
  - Гистограмма времени выполнения (в какое время суток пользователь чаще всего закрывает привычки: утро, день или поздний вечер).

### 2. Еженедельный срез (Weekly Breakdown)
- **Столбчатая диаграмма выполнения по неделям**:
  - Сравнение показателей за последние 8–12 недель.
  - Столбцы с цветовой градацией: >80% (зеленый/успех), 50–80% (желтый/стабильно), <50% (серый/требует внимания).
- **Лучшие и худшие дни недели**:
  - Радарная диаграмма или тепловая шкала «Пн — Вс», показывающая, в какие дни недели дисциплина наивысшая, а в какие наблюдаются просадки (например, на выходных).

### 3. Ежемесячный срез (Monthly Overview)
- **Календарный вид месяца (Calendar Matrix)**:
  - Полноразмерный календарь за выбранный месяц, где каждый день окрашен в цвет, отражающий процент выполнения всех запланированных привычек.
- **Диаграмма распределения по категориям (Donut / Pie Chart)**:
  - Круговая диаграмма баланса сфер жизни: Здоровье, Спорт, Разум, Продуктивность, Стиль жизни. Позволяет сразу увидеть перекосы (например, много внимания работе, но мало здоровью).

### 4. Рекомендуемая библиотека
- `recharts` — декларативная, легковесная и отлично интегрирующаяся с React и Tailwind диаграммная библиотека.

## ⏰ План расширения: Система напоминаний (ежедневные, еженедельные, ежемесячные)

### 1. Архитектура и технологии
- **Web Notifications API**:
  - Запрос разрешения пользователя (`Notification.requestPermission()`).
  - Отправка уведомлений в браузере при наступлении установленного времени.
- **Service Worker + Periodic Sync / Push API**:
  - Для работы напоминаний даже при закрытой вкладке браузера используется Service Worker.
  - Локальный таймер в фоновом воркере проверяет расписание привычек каждую минуту.

### 2. Структура данных напоминания (модель HabitReminder)
```typescript
export interface HabitReminder {
  id: string;
  habitId: string;
  enabled: boolean;
  type: 'daily' | 'weekly' | 'monthly';
  time: string; // Формат "HH:mm", например "08:30"
  daysOfWeek?: number[]; // [1, 2, 3, 4, 5] для понедельник-пятница
  dayOfMonth?: number; // 1-31 для ежемесячных напоминаний
  customMessage?: string; // Мотивирующий текст
}
```

### 3. Пользовательский интерфейс настроек напоминаний
- **Ежедневные**:
  - Выбор точного времени (например, 07:30 для «Выпить стакан воды», 22:00 для «Чтение книги»).
- **Еженедельные**:
  - Чекбоксы выбора конкретных дней недели (Пн, Вт, Ср, Чт, Пт, Сб, Вс) и времени срабатывания (например, воскресенье в 19:00 — «Планирование недели»).
- **Ежемесячные**:
  - Выбор числа месяца (например, 1-е число в 10:00 — «Подведение итогов месяца и постановка целей»).
- **Индикатор колокольчика в карточке привычки**:
  - Иконка колокольчика со статусом (активно/неактивно), быстрый просмотр времени следующего напоминания по наведению.

## 💻 Установка и запуск

1. **Установка зависимостей**:
   ```bash
   npm install
   ```

2. **Запуск сервера разработки**:
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу `http://localhost:3000`.

3. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
